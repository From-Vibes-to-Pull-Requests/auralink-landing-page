# Auralink Landing Page

This is a minimal [Next.js](https://nextjs.org/) landing page project for Vibes to Pull Requests workshop participants.

## Prerequisite

- Install [Node.js LTS](https://nodejs.org/en/download) (includes `npm`).

## Quick Start

```bash
git clone https://github.com/From-Vibes-to-Pull-Requests/auralink-landing-page
cd auralink-landing-page
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Common Workshop Commands

```bash
npm run dev
npm run build
```
